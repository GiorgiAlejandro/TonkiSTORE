# Distribucion de responsabilidades del equipo

Este proyecto fue desarrollado de manera colaborativa por tres integrantes, con una asignacion funcional de tareas por areas tecnicas.

## Mateo Porreca

- Diseno e implemento la base del backend utilizando Flask.
- Definio la estructura principal de la API para la gestion del catalogo de juegos.
- Desarrollo la capa de persistencia con SQLite y las operaciones CRUD sobre juegos.
- Implemento logica de consulta y busqueda de datos en el repositorio.

## Neo D'Angelo

- Desarrollo la interfaz frontend del catalogo publico.
- Implemento la renderizacion de vistas (listado y detalle) y la navegacion entre pantallas.
- Trabajo sobre interacciones de usuario, incluyendo busqueda y paginacion.
- Participo en la definicion de estilos y estructura visual de la experiencia principal.

## Alejandro Giorgi

- Realizo tareas de integracion entre frontend y backend para asegurar el flujo completo de datos.
- Reviso el codigo desarrollado por Mateo Porreca y Neo D'Angelo.
- Incorporo funcionalidades adicionales en ambos frentes (frontend y backend).
- Identifico y resolvio errores en las implementaciones de ambas areas.
- Colaboro en la estabilizacion general del proyecto antes de su entrega.
